📊 Dashboard de Vendas - Game Pass
Projeto de análise de dados desenvolvido no Excel com foco na criação de um dashboard para acompanhamento de métricas de vendas.

🛠️ O que foi feito
Durante o desenvolvimento do projeto, foram aplicados os seguintes conceitos:

Separação entre base de dados, cálculos e visualização
Organização dos dados em abas (Bases, Cálculos e Dashboard)
Utilização de fórmulas para cálculo de métricas
Uso de tabelas dinâmicas para análise de dados
Construção de indicadores (KPIs) como:

Total de assinantes
Receita total
Ticket médio
Taxa de auto renewal


Desenvolvimento de gráficos para apoio visual das análises
Criação de layout de dashboard no Excel
